Scenario 3: Provide a PID that does not exist
==================================================================

Timestamp                PID  Name              CPU %  Memory (MB)  Uptime
PID 4194305: no such process
None of the given PIDs could be monitored
[exit code: 1]

# Non-existent PID mixed with a valid one: the valid one is still monitored
$ procmon -p 4194305,11355 -i 1 -n 2
Timestamp                PID  Name              CPU %  Memory (MB)  Uptime
PID 4194305: no such process
2026-11-17 18:33:29    11355  sleep               N/A          7.9  00:00:00
2026-11-17 18:33:30    11355  sleep               0.0          7.9  00:00:01
[exit code: 0]

# Syntactically invalid PIDs are skipped with a warning
$ procmon -p abc,11355,,0 -i 1 -n 1

2026-11-17 18:33:30    11355  sleep               N/A          7.9  00:00:01
[exit code: 0]

==================================================================
Scenario 7: Stop the application using Ctrl+C (SIGINT)
==================================================================
# procmon runs without -n; SIGINT is sent after ~2.5 s (same signal as Ctrl+C)
$ procmon -p 1 -i 1   (then SIGINT)
Timestamp                PID  Name              CPU %  Memory (MB)  Uptime
2026-11-17 18:33:32        1  systemd             N/A         16.5  03:03:48
2026-11-17 18:33:33        1  systemd             0.0         16.5  03:03:49
2026-11-17 18:33:34        1  systemd             0.0         16.5  03:03:50

Stop signal received, exiting.
[exit code: 0]

# Same with SIGTERM (what 'systemctl stop' sends)

timestamp,pid,name,cpu_percent,memory_mb,uptime_s

# A process name containing a comma is quoted (RFC 4180)
$ procmon -p 11438 -n 1 -c
timestamp,pid,name,cpu_percent,memory_mb,uptime_s
2026-11-17 18:33:44,11438,"a,b",,2.0,0
[exit code: 0]
