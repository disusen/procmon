Scenario 3: Provide a PID that does not exist
==================================================================
$ procmon -p 4194305 -i 1 -n 2
Timestamp                PID  Name              CPU %  Memory (MB)  Uptime
PID 4194305: no such process
None of the given PIDs could be monitored
[exit code: 1]

# Non-existent PID mixed with a valid one: the valid one is still monitored
$ procmon -p 4194305,6728 -i 1 -n 2
Timestamp                PID  Name              CPU %  Memory (MB)  Uptime
PID 4194305: no such process
2026-11-16 20:38:05     6728  sleep               N/A          7.9  00:00:00
2026-11-16 20:38:06     6728  sleep               0.0          7.9  00:00:01
[exit code: 0]

# Syntactically invalid PIDs are skipped with a warning
$ procmon -p abc,6728,,0 -i 1 -n 1
warning: invalid PID skipped: abc
warning: invalid PID skipped: 0
Timestamp                PID  Name              CPU %  Memory (MB)  Uptime
2026-11-16 20:38:06     6728  sleep               N/A          7.9  00:00:01
[exit code: 0]

==================================================================
Scenario 7: Stop the application using Ctrl+C (SIGINT)
==================================================================
# procmon runs without -n; SIGINT is sent after ~2.5 s (same signal as Ctrl+C)
$ procmon -p 1 -i 1   (then SIGINT)
Timestamp                PID  Name              CPU %  Memory (MB)  Uptime
2026-11-16 20:38:08        1  systemd             N/A         16.5  02:00:39
2026-11-16 20:38:09        1  systemd             0.0         16.5  02:00:40
2026-11-16 20:38:10        1  systemd             0.0         16.5  02:00:41

Stop signal received, exiting.
[exit code: 0]

# Same with SIGTERM (what 'systemctl stop' sends)
$ procmon -p 1 -i 1   (then SIGTERM)
Timestamp                PID  Name              CPU %  Memory (MB)  Uptime
2026-11-16 20:38:11        1  systemd             N/A         16.5  02:00:42
2026-11-16 20:38:12        1  systemd             0.0         16.5  02:00:43
2026-11-16 20:38:13        1  systemd             0.0         16.5  02:00:44

Stop signal received, exiting.
[exit code: 0]
